# Bible Word Pronunciation Web App

A responsive React app to search difficult Bible names and hear **real pronunciation audio** generated by Google Cloud Text-to-Speech.

## Features

- Search 50+ difficult Bible words with phonetic spellings
- Real-time pronunciation generation using Google Cloud Text-to-Speech
- Loading state while audio is being generated
- Friendly error messaging when generation fails
- Audio caching in:
  - backend memory cache (to reduce repeated TTS calls)
  - browser `localStorage` cache (faster replay per user)

## Google Cloud Text-to-Speech setup

1. In Google Cloud Console, enable **Cloud Text-to-Speech API**.
2. Create an API key with Text-to-Speech access.
3. Set the key in your shell:

   ```bash
   export GOOGLE_TTS_API_KEY="your_google_tts_api_key"
   ```

## Run locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start backend API (Terminal 1):

   ```bash
   npm run dev:backend
   ```

3. Start frontend (Terminal 2):

   ```bash
   npm run dev
   ```

4. Open the Vite URL shown in terminal (usually `http://localhost:5173`).

## API endpoint

- `POST /api/pronounce`
  - Request body:

    ```json
    {
      "word": "Nebuchadnezzar",
      "phonetic": "neb-yoo-kad-NEZ-er"
    }
    ```

  - Response body:

    ```json
    {
      "audioContent": "<base64 mp3>",
      "mimeType": "audio/mpeg",
      "cached": false
    }
    ```
